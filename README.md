# 📻 하늘교 '하멘' 성전

> **SPOON RADIO DJ 하늘**님을 향한 팬들의 마음과 기도를 모으는 실시간 참여형 웹 서비스입니다.  
> 버튼 클릭 한 번으로 소원과 메시지를 남기고 실시간으로 성도들의 기도를 공유할 수 있습니다.

---

## 🌟 주요 특징 (Key Features)

- **🙏 하멘 기도 바치기**
  - 메인 '하멘' 버튼을 눌러 하늘님께 보낼 기도와 메시지를 올릴 수 있습니다.
  - 연연속 등록 방지를 위해 **1시간 쿨타임 타이머**가 작동합니다.

- **✨ '아멘' ➔ '하멘' 자동 정정**
  - 기도문 작성 중 실수로 `'아멘'`이라 입력하면, 자동으로 **`'하멘'`**으로 교정된 후 저장됩니다.
  - 정정 후에는 알아보기 쉽게 중앙 모달 팝업으로 안내합니다.

- **📜 실시간 기도 모음**
  - 모든 신도들이 작성한 기도를 실시간으로 업데이트합니다.
  - 최근 기도를 한눈에 볼 수 있으며, '전체보기'를 통해 이전 기도 기록을 확인할 수 있습니다.

- **👤 닉네임 & 디바이스 상태 저장**
  - 나만의 닉네임을 설정할 수 있으며, 랜덤 닉네임 자동 생성 기능도 제공합니다.
  - 브라우저에 접속 기록과 쿨타임 상태가 유지됩니다.

- **⏰ 한국 표준시(KST) 타임스탬프**
  - 접속 환경과 상관없이 항상 한국 시간(UTC+9) 기준으로 작성 시간이 기록됩니다.
