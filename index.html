깃허브 Pages 무료 배포 안내

  1. GitHub 접속 및 로그인: github.com에 로그인 후 New repository 버튼을 누릅니다.
  2. 리포지토리 생성: Repository name에 예: haneul-hamen 입력 후 Public으로 설정하고 Create repository를 클릭합니다.
  3. 파일 업로드: 생성된 페이지에서 uploading an existing file 클릭 후, 이 코드 전체를 index.html 이름의 파일로 저장하여 올립니다.
  4. Commit 변경: 하단의 Commit changes 버튼을 누릅니다.
  5. Pages 활성화: 저장소 상단 Settings ➔ 좌측 메뉴 Pages 선택 후, Branch를 main (또는 master)으로 바꾸고 Save를 누릅니다.
  6. 배포 완료: 1~2분 후 나오는 생성된 주소(URL)로 접속하면 스푼라디오 팬들과 함께 사용할 수 있는 사이트 완성!
